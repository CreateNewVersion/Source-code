# CreateNewVersion

### Create. Reimagined for Newer Versions.

**CreateNewVersion** is a community-driven port of the original Create Mod, bringing its unique world of mechanical engineering, automation, and creative building to newer Minecraft versions.

Built for **Fabric and NeoForge**, CreateNewVersion aims to keep the Create experience alive as Minecraft continues to evolve.

---

## About

Welcome to **CreateNewVersion**, a project dedicated to bringing the creativity and engineering possibilities of Create to modern Minecraft versions.

Create introduces a unique approach to technology, where machines are not simply controlled through menus but built from moving, interconnected mechanical components.

From rotating shafts and spinning gears to elaborate factories and automated production lines, the possibilities are limited only by your imagination.

**Build it. Power it. Automate it.**

## Features

-  **Kinetic Engineering** – Design mechanical systems using rotational power, gears, shafts, and moving components.
-  **Creative Automation** – Construct automated factories, processing systems, and production lines.
-  **Mechanical Contraptions** – Build impressive moving machines and engineering creations.
-  **Building & Decoration** – Combine technology with beautiful, functional designs.
-  **Modern Minecraft Support** – Bringing the Create experience to newer Minecraft versions.
-  **Fabric & NeoForge** – Designed to support both modding ecosystems.

## Our Goal

Minecraft keeps moving forward, and we believe Create should move forward with it.

The goal of CreateNewVersion is to preserve the original Create experience while making it accessible on newer versions of Minecraft.

We aim to maintain the creativity, mechanical depth, and unique visual style that make Create special.

## Installation

1. Install a supported version of **Fabric** or **NeoForge**.
2. Download the CreateNewVersion file matching your Minecraft version and mod loader.
3. Install any required dependencies listed for that release.
4. Place the mod in your `mods` folder.
5. Launch Minecraft and start creating!
